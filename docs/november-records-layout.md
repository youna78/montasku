# 冒険の記録の構成変更

2026年11月1日0時（日本時間）以降、`/records` は添付イメージに沿った新構成を使用する。それ以前は従来の構成を維持。検証カレンダーの仮想日時でも切り替わる。

- 上段：現在の連続ログイン、達成タスク数
- 下段：記録された獲得EXP、出会ったモンスター数（卵を除く）、記録された獲得コイン
- 今週の活動（月曜〜日曜）と、その週の達成件数
- 月ごとの冒険。長い履歴は横スクロールでき、初期位置は最新月
- 手紙一覧へのリンク（所持数）とホームへのリンク

集計は既存の `summarizeRecords` を使用。コインは所持残高ではなく、記録に保存された獲得コインの合計。連続ログインはイベント累計ログインとは別の `streakDays`。記録機能追加以前の一部データが含まれない注意書きを維持。

既存のゲーム画像とCSSで構成し、各数値・グラフの文字は実データとして描画する。見本はローカルの `/dev/records`（サンプル値のみ、セーブ変更なし）。

検証：日本時間での切替境界、翌年も新構成を維持、月をまたぐ週、空の履歴、報酬不明の履歴をテスト。既存の記録・10月イベントのテスト、TypeScript型チェックも実施。PCと390pxのスマホ幅で表示確認。
